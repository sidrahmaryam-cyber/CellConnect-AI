# CellConnect AI

**An LLM-powered research assistant for cell–cell communication analysis.**

CellConnect AI aims to help biomedical researchers explore cell–cell communication (CCI) using public single-cell and spatial transcriptomics datasets.

## Planned Features

- Load and explore public single-cell transcriptomics datasets.
- Identify candidate ligand–receptor interactions using established CCI methods.
- Use a locally running LLM to coordinate analysis tools.
- Retrieve relevant biomedical literature from PubMed.
- Generate evidence-based summaries and visualizations.
- Provide an interactive research interface.

## Technology Stack

- Python
- Scanpy and AnnData
- LIANA+ for cell–cell communication analysis
- Ollama for local LLM inference
- Biopython and PubMed
- Streamlit
- LangGraph
- Git and GitHub

## Project Status

Early development. Features will be implemented and tested incrementally.

## Scientific Scope

Predicted ligand–receptor interactions are hypotheses, not proof of direct biological communication. Results will be interpreted alongside expression data, methodological limitations, and published evidence.

## Data and Reproducibility

Public datasets will be cited in the project documentation. Large datasets and generated results will not be committed to the repository.
